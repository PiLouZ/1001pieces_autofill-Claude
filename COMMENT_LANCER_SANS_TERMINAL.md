# 🚀 Comment lancer l'application

## 🎯 **Solution recommandée :**

### ⌨️ **Fichier de lancement (.command) - SOLUTION FIABLE**
- **Double-cliquez** sur `Lancer_1001pieces.command`
- ✅ **Lancement** : Simple et fiable
- ✅ **Vérifications** : Automatiques (Python, PyQt5)
- ✅ **Messages** : Clairs en cas de problème
- ✅ **Utilisateurs** : Parfait pour tous les utilisateurs

## 🛠️ **Solutions alternatives :**

1. **Ligne de commande** : `python3 run.py`
2. **Bundle .app** : `1001pieces_autofill.app` (peut ne pas fonctionner sur certains systèmes)

## 💡 **Astuces :**

- **Glissez** `Lancer_1001pieces.command` dans votre Dock pour un accès rapide
- **L'application** vérifie automatiquement les dépendances au démarrage
- **Terminal** reste ouvert pour voir les messages, se ferme automatiquement
