Points clés de l'architecture

Performance & Volumétrie

  • FTS5 trigram index : recherche full-text sur la table appareils
  • Cache adaptatif : invalidation sélective des recherches
  • Lazy loading PDF : chargement différé après ouverture
  • EventDrivenSaveService : sauvegarde <100ms (vs 5000ms avant v3.14)
  • PRAGMA SQLite : synchronous=NORMAL, cache 64Mo, mmap 256Mo

Fonctionnalités avancées

  • Supersession : gestion des références obsolètes via CTE récursive
  • Suggestions Type/Marque par similarité : rapprochement de références quasi-identiques (variantes de suffixe, fuzzy matching, consensus de préfixe), garde anti-rebadging sur préfixe numérique, validation systématique par l'utilisateur (fenêtre dédiée, acceptation inline, copie des références)
  • Relations par groupes à l'import multi-fichiers : lignées de succession et groupes d'équivalence déclarés visuellement (glisser-déposer, promotion en référence courante), dérivation automatique des obsolescences
  • Undo/Redo : historique complet avec fusion d'éditions
  • Backup automatique : copies de sécurité SQLite natives (3 copies rotatées)
  • Imports multiformat : CSV, PDF (via Camelot)
  • Exports : HTML (avec escape XSS), CSV, profils personnalisés

Qualité du code

  • ZERO REGRESSION : refactorings vérifiés à chaque commit
  • Code mort éliminé itérativement : 3300+ lignes supprimées aux points fixes
  • AST-based removal : suppression précise sans casser multi-lignes
  • 379 tests unitaires (6 échecs préexistants documentés comme baseline)
