Guide d'utilisation — 1001pieces.com

Démarrage rapide

Importer des données

  1. Fichiers PDF ou CSV : bouton Importer de la barre d'outils, ou glisser-déposer les fichiers sur le tableau.
  2. Collage : copiez des lignes depuis Excel ou Calc, puis Cmd+V dans le tableau.
  3. Référence de pièce : elle est remplie d'après le nom du fichier ; vous pouvez la modifier et lui donner un libellé avant d'importer.
  4. Progression : la fenêtre d'import affiche une ligne par étape (extraction, finalisation, suggestions…) avec sa durée.

Retrouver les appareils d'une pièce

  • Tapez la référence dans Recherche par pièce (sous le tableau, ou au-dessus selon Affichage → Recherche pièce en haut du tableau).
  • Plusieurs références : ref1 || ref2 (OU). Combinaison : ref1 && ref2 (ET).
  • La recherche est exacte par défaut ; le bouton loupe à droite du champ la rend partielle.
  • Si la pièce a été remplacée ou a des équivalences, un bandeau le signale au-dessus du tableau.

Panneau de droite

  • Pièces de l'appareil sélectionné (ou pièces communes à plusieurs appareils sélectionnés).
  • Ajouter une pièce : bouton +, puis saisie de la référence et du libellé. Entrée ajoute, Échap annule ; la pastille indique à combien d'appareils la pièce sera ajoutée. La pièce ajoutée est surlignée en vert un instant.
  • Historique des opérations : chaque action, avec un badge par type (Modif., Import, Export, Suppr., Erreur, Annul., Pièce, Système). L'icône à côté du titre ouvre l'historique complet.
  • Exports : HTML Marques, HTML Détails, CSV et métas SEO (Méta Title, Méta Desc ; Maj+clic pour une autre formulation). Ils s'activent après une recherche par pièce.

Barre d'état

  • Lignes à traiter ▲ ▼ : passe d'une ligne incomplète (Type ou Fabricant manquant) à la suivante.

Éditer le tableau

  • Double-clic ou F2 sur une cellule pour la modifier. Taper sur une cellule déjà remplie ne la modifie pas : c'est voulu, pour éviter les écrasements accidentels.
  • Entrée : passe à la ligne suivante, même colonne.
  • Suppr / Retour arrière : vide les cellules sélectionnées.
  • Cmd+D : liste des valeurs déjà utilisées dans la colonne (sauf colonnes de référence).
  • Suggestions : quand le Type ou le Fabricant manque, l'import peut proposer une valeur d'après des références proches. Les cellules concernées sont teintées ; un clic montre les candidats.

Relations entre références

À l'import de plusieurs fichiers

  • Lignées de succession (bleu) : glissez les anciennes références dans une lignée et indiquez sa courante (double-clic sur une réf pour la promouvoir). Les anciennes deviennent obsolètes.
  • Groupes d'équivalence (violet) : glissez les références interchangeables dans un même groupe.
  • Équivalence entre zones : cochez « Équivalente » sur plusieurs lignées ou groupes ; une référence de chaque zone cochée (la courante d'une lignée, la première réf d'un groupe) est déclarée équivalente aux autres. Il faut au moins deux zones cochées portant une référence.
  • Le récapitulatif en bas indique ce qui sera réellement créé ; une alerte orange signale une déclaration sans effet et sa cause.

Dans le gestionnaire de pièces

  • Sélectionnez une pièce : le panneau de droite affiche ses équivalences, ce qu'elle remplace et ce qui la remplace. Les boutons + ajoutent une relation.
  • Filtres en haut : orphelines, fantômes, sans libellé, obsolètes, remplacées, remplaçantes, équivalentes, libellés incohérents.
  • Cmd+Clic pour sélectionner plusieurs pièces et appliquer une action groupée.

Nouveautés de la version 3.78

  • Historique plus lisible : badges en clair, type Erreur distinct de Suppression, une entrée sur deux lignes.
  • Hauteur des lignes réglable (Affichage → Hauteur des lignes) et une ligne sur deux teintée.
  • Ajout de pièce repensé : carte en tête de liste, Entrée / Échap, pièce ajoutée surlignée.
  • Progression d'import : une ligne par étape avec sa durée.
  • Gestionnaire de pièces : colonne Statut complète, messages quand une relation est vide.
  • Alertes de relations à l'import : elles nomment la cause (zone cochée mais vide, lignée sans courante).

Dépannage

Problèmes d'import

  • Vérifiez l'encodage du fichier CSV (UTF-8 recommandé) et qu'il compte au moins 2 colonnes.
  • Si la première ligne contient des noms de colonnes, cochez « 1ʳᵉ ligne = en-têtes ».
  • Si les colonnes sont mal reconnues, ouvrez « Adapter le mapping » sous l'aperçu.

Revenir en arrière

  • Une copie de la base est faite avant chaque nettoyage de doublons, et avant un import (au plus une par 24 h). Configuration → Restaurer une sauvegarde… remet une copie en place.

Déploiement sur une autre machine

Générer le dossier d'export

  1. Configuration → Exporter l'application…
  2. Choisissez un dossier de destination (Bureau recommandé).
  3. Patientez 1 à 2 minutes (téléchargement des dépendances).
  4. Un dossier 1001pieces_export_AAAAMMJJ_HHMM/ est créé.

Sur le poste cible (macOS)

Prérequis : Python 3.10 ou plus récent (python3 --version pour vérifier).

  1. Double-cliquez sur install.command : installe les dépendances (une seule fois).
  2. Double-cliquez sur 1001pieces_autofill.app : lance l'application.
Aucune connexion internet n'est nécessaire sur le poste cible : les dépendances sont incluses.

Assistance

En cas de problème, consultez les logs via Journal dans la barre d'outils (ou F12).
