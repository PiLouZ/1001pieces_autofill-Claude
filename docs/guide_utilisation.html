Guide d'utilisation — 1001pieces.com

Mac ou Windows ? Ce guide écrit Cmd (touche ⌘ du Mac). Sous Windows, utilisez Ctrl à la place : Cmd+S devient Ctrl+S, Cmd+Clic devient Ctrl+Clic, etc. Tout le reste est identique.

Démarrage rapide

Importer des données

  1. Fichiers PDF ou CSV : bouton Importer de la barre d'outils, ou glisser-déposer les fichiers sur le tableau.
  2. Collage : copiez des lignes depuis Excel ou Calc, puis Cmd+V dans le tableau.
  3. Référence de pièce : elle est remplie d'après le nom du fichier ; vous pouvez la modifier et lui donner un libellé avant d'importer.
  4. Aperçu : avant de valider, la fenêtre montre ce qui sera créé. Un encadré « Orthographe alignée sur la base » annonce les marques et types réécrits (ex. MIDEA → Midea, déjà présent en base).
  5. Progression : une ligne par étape (extraction, finalisation, suggestions…) avec sa durée.
  6. Plusieurs fichiers : un appareil créé par un fichier et cité par un fichier suivant du même import est relié aux deux pièces dès le premier import.
Pour essayer sans risque : le dossier fichiers_test_import, livré avec l'application exportée, contient quelques PDF et un CSV d'exemple.

Ce que l'import complète tout seul

  • Auto-complétion : un appareil importé sans Type ou sans Fabricant reçoit celui d'un appareil de même référence déjà en base. Un appareil existant dont le Type ou le Fabricant est vide est complété de la même façon ; une valeur déjà saisie n'est jamais écrasée.
  • Le bouton Données → Autocomplétion applique exactement la même règle aux lignes affichées : une valeur auto-complétée pas encore vérifiée ne sert pas de modèle, une valeur refusée n'est pas reproposée, et ce qu'il complète apparaît dans Auto-complétés à vérifier comme après un import.
  • Ces valeurs déduites s'affichent dans le tableau en italique, sur fond lavande, avec une coche bleue à droite de la case ; le numéro de la ligne passe en orange gras sur fond orange pâle. Ces repères restent jusqu'à la vérification (voir Vérifier les auto-complétés ci-dessous).
  • Règles de nomenclature : un appareil importé sans Type (ou dont le Type vient de l'auto-complétion) reçoit celui d'une règle validée qui correspond à sa marque et à sa référence (par exemple Gaggenau BS… → Four vapeur). Il passe dans Auto-complétés à vérifier, avec la règle pour source. Un Type lu dans le fichier n'est jamais remplacé : s'il contredit une règle validée, l'appareil le garde et reçoit un type proposé (bouton Types proposés). Un Type absent de la liste des types du site (par exemple « Cocotte ») est gardé et signalé. Une règle seulement proposée ne joue jamais, et un type refusé n'est jamais réécrit. La fenêtre de prévisualisation annonce ces trois cas avant d'importer, et l'historique les reprend.
  • Marque collée retirée des références : quand un fichier écrit la marque dans la référence (« SMEG ST995 » en référence modèle, « ST995 SMEG » en référence commerciale), elle est retirée et l'appareil est enregistré sous « ST995 ». L'import retrouve ainsi l'appareil déjà en base au lieu d'en créer un double. La marque n'est retirée que si le mot est la marque de la ligne, séparé par un espace, et qu'il reste une référence avec un chiffre. Le chauffage n'est jamais touché, car sa référence commerciale est une désignation (« SAUTER VENISE VENTILO 1500 W »). La prévisualisation et l'historique l'annoncent sous Orthographe alignée sur la base.
  • Écritures de marque : « Glem » devient « Glem Gas », « Concord » devient « Concorde », à l'import comme à la saisie dans le tableau.
  • Suggestions : quand rien ne permet de déduire la valeur, l'import propose un Type / une Marque d'après des références proches, ou le type que portent déjà les appareils de la pièce. Rien n'est écrit sans votre validation (voir ci-dessous).

Retrouver les appareils d'une pièce

  • Tapez la référence dans Recherche par pièce (sous le tableau, ou au-dessus selon Affichage → Recherche pièce en haut du tableau).
  • Plusieurs références : ref1 || ref2 (OU). Combinaison : ref1 && ref2 (ET).
  • La recherche est exacte par défaut ; le bouton loupe à droite du champ la rend partielle.
  • Si la pièce a été remplacée ou a des équivalences, un bandeau le signale au-dessus du tableau ; il permet d'inclure les anciennes références ou les équivalentes.

Filtres au-dessus du tableau

  • Un champ par colonne. Pour Type et Marque, la flèche déroule la liste complète ; la frappe filtre dès la 1ʳᵉ lettre, sur une partie du mot.
  • Recherches plus fines (bouton ? à gauche du ✕, ou bulle au survol d'un champ) : WOI4S = contient WOI4S ; WOI* = commence par WOI ; *S = finit par S ; ? = un seul caractère (WOI?S* trouve WOI4S…, WOI5S…) ; WOI4S* | WOI5S* = l'un ou l'autre ; WOI* !WOI9* = sauf ceux qui commencent par WOI9. Sans * ni ?, le champ cherche « contient » ; avec, il décrit la valeur entière : WOI*S veut dire « commence par WOI et finit par S ». Majuscules et minuscules sont confondues. Marche aussi pour Type et Marque (Lave-linge | Sèche-linge).
  • Le bouton ✕ (au-dessus de la colonne Pièces) efface tous les filtres.

Panneau de droite

  • Pièces de l'appareil sélectionné. Avec plusieurs appareils sélectionnés : les pièces communes, y compris celles portées sous des références différentes d'une même lignée (mention « ⇄ Commune par lignée »).
  • Ajouter une pièce : bouton +, puis saisie de la référence et du libellé. Entrée ajoute, Échap annule ; la pastille indique à combien d'appareils la pièce sera ajoutée. La pièce ajoutée est surlignée en vert un instant. Sans appareil sélectionné, la pastille affiche « Pièce seule » et le bouton devient Créer : la pièce est créée au catalogue sans être associée à un appareil, comme avec « + Nouvelle pièce » du gestionnaire de pièces. Si la référence existe déjà, rien n'est modifié.
  • Historique des opérations : chaque action, avec un badge par type (Modif., Import, Export, Suppr., Erreur, Annul., Pièce, Système). Les 100 dernières entrées sont rechargées à l'ouverture. Les alertes d'import (pages vides d'un PDF, colonnes mal reconnues) sont surlignées en jaune. L'icône ↗ à côté du titre ouvre l'historique complet.
  • Exports : sur la 1ʳᵉ ligne Méta Title, Méta Desc (Maj+clic pour une autre formulation) et Exporter CSV ; sur la 2ᵉ Titre (un tiers) et Fiche complète (deux tiers). HTML Marques et HTML Détails sont repliés sous « ▸ Exports HTML » : un clic déplie ou replie la ligne (mémorisé sur le poste). Les boutons s'activent après une recherche par pièce. Sur Titre, Fiche complète et HTML Détails, la flèche : la survoler ouvre la liste des autres gabarits (par ordre alphabétique ; à partir de 6 gabarits, champ « Filtrer… » et vos 3 gabarits récents en tête) ; cliquer dessus ouvre l'aperçu d'export. Le reste du bouton exporte avec le gabarit par défaut.
  • Aperçu d'export : fenêtre qui montre l'export de chaque gabarit sur la recherche en cours. À gauche l'onglet Rendu (tel qu'affiché sur le site) et l'onglet Code (coloré, indenté) ; à droite, près des boutons, les gabarits (★ = celui du clic sur le bouton, champ de filtre ; les noms longs passent à la ligne, jamais coupés) ; en dessous, caractères, appareils, marques et réduction éventuelle. Copier (ou double-clic sur un gabarit) copie exactement ce qui est affiché, puis ferme la fenêtre pour revenir sur la fenêtre principale ; Par défaut en fait le gabarit du clic sur le bouton ; Modifier le modèle… l'ouvre dans la configuration des exports. Tant que vous ne copiez pas, la fenêtre reste ouverte pendant que vous travaillez et suit les nouvelles recherches ; avec plusieurs références, Actualiser propose de choisir.
  • Titre : copie le titre de la fiche produit, par défaut « libellé pour type marques - référence la plus récente ». Taper une ancienne référence donne le titre de la courante. Jusqu'à 4 marques (les plus représentées) et 120 caractères : au-delà, les dernières marques puis les types en plus sont retirés, jamais le libellé ni la référence. Plusieurs types sont cités quand ils couvrent à peu près autant de modèles. Gabarits réglables dans Configuration des exports, onglet Titre (aperçu en direct ; séparateurs distincts pour les marques et pour les types ; case Varier le nom de l'appareil, décochée par défaut, pour citer « machine à laver » au lieu de « lave-linge » selon l'onglet Appareils, utile pour un gabarit repris dans une description) ; avec plusieurs gabarits, la flèche du bouton propose les autres.
  • Fiche complète : copie tout le code HTML de la fiche produit, dans l'ordre : titre, « Compatible avec » (marques), code produit, « Remplace les références », « Références équivalentes » (chaque équivalente suivie de ses anciennes références, de la plus fournie en appareils à la moins fournie ; à égalité, celles qui commencent par une lettre d'abord), bloc Informations facultatif, puis la liste des appareils. Le code produit est la référence tapée ; une ancienne référence donne la fiche de la courante. Pour une pièce reprise du site, la fiche se réécrit comme sur le site : le code produit garde sa paire (« 481073071153 C00319033 », les anciennes références des deux allant dans « Remplace », dans l'ordre de la fiche du site : « C00535957 488000535957 C00309416 482000032568 »), une ligne « Références équivalentes » par marque d'origine (BSH, Candy…), et les références écartées à la reprise n'apparaissent plus parmi les équivalentes (une ancienne référence écartée reste dans « Remplace »). Deux références associées (Whirlpool / Indesit / Beko) se suivent toujours sur la même ligne : la jumelle d'une ancienne référence va dans « Remplace », juste derrière elle. Sans marque d'origine connue, toutes les équivalentes restent sur une seule ligne. Une ligne sans référence n'est pas écrite. Marques et appareils sont ceux affichés dans le tableau : une recherche inclut d'office les appareils des références équivalentes (bandeau ≡) ; « Voir uniquement … » les retire. La limite (200 000 caractères par défaut) porte sur la fiche entière : au-delà, la liste des appareils est réduite comme pour HTML Détails. Variantes dans Configuration des exports, onglet Fiche : gabarit Titre et profil de liste d'appareils utilisés, texte de chaque ligne, bloc Informations (« Fiche avec informations » l'inclut, à compléter ensuite sur le site).
  • Exporter CSV (EveryParts) : la fenêtre demande la référence d'export, écrite dans la colonne product et dans le nom du fichier. Pour une pièce vendue sur le site, elle propose la référence interne de son produit (« EL1113161010 » pour 1113161010), toujours modifiable ; une ancienne référence propose celle de la pièce courante (00703010 → « GAU11051894 »). Une pièce vendue sous plusieurs produits affiche une liste « Produit du site » pour choisir. Sans produit, la référence recherchée est proposée, comme avant. Dans Configuration des exports, onglet CSV, les variables {ref_interne} et {id_product} (n° du produit sur le site) s'ajoutent aux colonnes et au nom du fichier ; le format par défaut ne change pas.
  • Configuration des exports : le code HTML des modèles est coloré (balises, attributs, valeurs, &nbsp;, variables sur fond jaune) et indenté à l'écran, un bloc par ligne. Ce qui est enregistré et exporté ne change pas : l'indentation n'existe qu'à l'affichage. Entrée passe à la ligne entre deux balises ; l'indentation est refaite en quittant la zone.
  • Configuration des exports, onglets HTML, Titre et Fiche : trois colonnes séparées par des poignées que l'on déplace à la souris. À gauche, la liste des gabarits (profils HTML Détails, gabarits Titre, variantes Fiche) : celui par défaut en tête avec une étoile, les autres par ordre alphabétique, noms longs sur plusieurs lignes ; champ « Filtrer… » dès 6 gabarits ; boutons Nouveau / Dupliquer / Supprimer dessous et toutes les actions au clic droit. Au centre, les réglages, avec en tête le champ Nom (renommer directement ; aussi par double-clic ou F2 dans la liste ; un nom vide ou déjà pris est refusé) et le bouton Par défaut. À droite, l'aperçu. Taille de la fenêtre et largeur des colonnes sont mémorisées par poste. Onglet Fiche : une carte par bloc, dans l'ordre où la fiche est écrite (1 Titre … 7 Liste des appareils) ; listes Titre et Liste des appareils triées, « Gabarit par défaut (nom) » en tête ; « Modifier ce gabarit › » ouvre le gabarit dans son onglet, un bandeau « ‹ Retour à la fiche » ramène à la variante. Un gabarit Titre ou un profil HTML Détails renommé l'est aussi dans les variantes qui l'utilisent.
  • Configuration des exports, onglet Appareils : les autres appellations de chaque type d'appareil dans les textes générés (« machine à laver » pour « lave-linge »). Le type en base garde une part réglable (50 % par défaut) ; les autres appellations actives se partagent le reste. Le choix est fixe pour une référence : régénérer une fiche ne le change pas. En revanche, modifier la liste peut changer le texte des fiches déjà exportées. Texte concerné par défaut : la méta description. Le méta title garde le type en base, sauf si vous cochez sa case. Les titres se règlent gabarit par gabarit, dans l'onglet Titre (case « Varier le nom de l'appareil »). Une appellation qui obligerait à retirer une marque, une référence ou un mot est remplacée par le type en base. À gauche, les types d'appareils et leur genre (pour écrire « un » ou « une ») ; à droite, les appellations du type sélectionné, chacune avec son genre, sa nature et une case Active. Un sous-type (« radiateur », « sèche-serviette » ou « accumulateur » pour « chauffage ») ne correspond qu'à une partie des appareils : il est livré désactivé. En bas, l'aperçu donne la part de chaque appellation par texte, ainsi que l'accord. La colonne Type, les filtres, la recherche et le CSV ne changent pas.

Barre d'état (sous le tableau)

  • Lignes à traiter ▲ ▼ : passe d'une ligne incomplète (Type ou Fabricant manquant) à la suivante.
  • ▲ Auto-complétés à vérifier (N) | Tout valider ▼ : visible quand des valeurs auto-complétées attendent une vérification (voir plus bas). Les flèches passent d'une ligne auto-complétée à la suivante.
  • ▲ Types proposés (N) ▼ : visible quand une règle de nomenclature propose un autre type pour des appareils (voir Règles de nomenclature). Les flèches passent d'un type proposé au suivant.
  • À droite : l'icône disquette (sauvegarde) et la pastille (connexion à la base) sont vertes quand tout va bien, orange pendant une sauvegarde ou s'il reste des changements non enregistrés. Survolez-les pour lire l'état. Tout à droite, la version de l'application.

Éditer le tableau

  • Double-clic ou F2 sur une cellule pour la modifier. Taper sur une cellule déjà remplie ne la modifie pas : c'est voulu, pour éviter les écrasements accidentels.
  • Entrée : passe à la ligne suivante, même colonne.
  • Suppr / Retour arrière : vide les cellules sélectionnées.
  • Cmd+D : liste des valeurs déjà utilisées dans la colonne (sauf colonnes de référence).
  • Une valeur pour plusieurs lignes : sélectionner plusieurs lignes dans la colonne Type ou Fabricant (Maj+clic, Cmd+clic pour des lignes éparses), puis Cmd+D ou taper la première lettre sur une case vide : la valeur choisie va à toutes les lignes sélectionnées, déjà remplies comprises. Le titre de la fenêtre annonce le nombre de lignes. Un seul Cmd+Z annule le tout. L'historique garde une ligne par appareil.
  • Marque et Type : une valeur tapée reprend l'orthographe déjà présente en base (bosch → Bosch).
  • Ajouter un appareil (Cmd+N) pendant une recherche : la nouvelle ligne apparaît en tête du tableau, sur fond pêche, même si elle ne correspond pas à la recherche ni aux filtres, et quel que soit le tri. Elle y reste tant que la recherche et les filtres ne changent pas. Plusieurs ajouts de suite s'empilent, le plus récent en haut.
  • Créer l'appareil qu'on cherche : quand une référence tapée dans un filtre (Réf. modèle, commerciale ou autre) ne trouve rien, un bouton Créer l'appareil « … » apparaît sous « Aucun résultat ». Ce bouton, comme Cmd+N, crée l'appareil avec cette référence. Il reprend aussi la marque et le type filtrés s'ils existent déjà en base (bosch → Bosch). Le curseur se place ensuite sur la première case vide (Type ou Fabricant), et un seul Cmd+Z retire les valeurs reprises. Un filtre avec joker (* ?), | ou ! n'est pas repris.
  • Four combiné micro-ondes : type à part entière, comme « Four vapeur », pour les fours compacts avec micro-ondes (niche de 45 cm) : Bosch CMG et HMG récents, Siemens CM / HM récents, Neff C17M…, AEG KMK, Gaggenau BM, Electrolux EVY… Le micro-ondes simple reste « Micro-ondes ». Le libellé est celui du site, au caractère près : ne pas le réécrire autrement. Dans les textes générés, il peut se dire « four micro-ondes combiné » ; « four micro-ondes » ne désigne plus le micro-ondes simple.
  • Poignée de recopie (petit carré en bas à droite de la sélection), comme dans un tableur :
    • glisser vers le bas ou vers le haut recopie la valeur (ou le motif de plusieurs lignes) ;
    • double-clic remplit vers le bas les cases vides ; s'il n'y a rien à remplir en bas, il remplit vers le haut.

Valider les suggestions

  • Les cellules avec une suggestion sont teintées ; un clic montre les candidats.
  • Le bouton ambre « Suggestions à valider (N) », sous le tableau à côté des lignes incomplètes, ouvre la fenêtre de validation.
  • Chaque ligne a un état : ✓ validée, ✗ refusée ou · en attente. Les suggestions sûres arrivent validées. Raccourcis : V valider, R refuser, U remettre en attente, Espace bascule ✓ / ·, Entrée ou double-clic pour corriger le type, M pour donner une marque. Sur une ligne de groupe, la décision vaut pour tout le groupe.
  • Corriger plusieurs lignes d'un coup : avec plusieurs lignes sélectionnées, ou une ligne de groupe (par exemple « Pièce … » en regroupant par Appareil voisin), Corriger (Entrée) donne le même type à toutes, et le bouton Marque… (M) la même marque. C'est le geste prévu pour les lignes « type seul » (type de la pièce, autre référence), dont la marque restait à saisir dans le tableau. Les lignes corrigées passent validées.
  • Les lignes sont regroupées par preuve (même référence, référence voisine, type de la pièce, autre référence, famille de préfixe) ; les puces du haut filtrent, dont ⚠ À risque. Le panneau de droite détaille la preuve, ce que disent les pièces de l'appareil et les autres candidats (lien Prendre).
  • Autre référence : quand la colonne « Autre référence » porte une désignation déjà vue (« Lave-vaisselle tout-intégrable », « Side by side »…), le Type de la plupart des appareils qui ont ce même texte est proposé (au moins 5 appareils, à 95 % ou plus). C'est un indice, pas une certitude : un fichier peut être mal étiqueté. Seul le Type est proposé, la marque reste à saisir ; si une autre preuve propose un type différent, les deux candidats s'affichent et la ligne n'est pas validée d'office.
  • Appliquer (⌘ Entrée) enregistre sans fermer : on peut traiter une longue liste en plusieurs fois. Une suggestion refusée n'est plus jamais proposée pour cet appareil.

Vérifier les auto-complétés

  • Bouton bleu « Auto-complétés à vérifier (N) » : ouvre la liste, regroupée par import. Tout est validé d'office ; mettez en attente ce qui est douteux, corrigez par double-clic, puis Appliquer. Mêmes raccourcis que pour les suggestions ; le panneau de droite confronte la valeur écrite aux pièces de l'appareil.
  • Flèches ▲ ▼ de part et d'autre du bouton : elles mènent dans le tableau à la ligne auto-complétée précédente ou suivante, même sur une autre page, quelle que soit la colonne sélectionnée. Le curseur se place sur la case à contrôler (Type, sinon Fabricant). Raccourcis ⇧⌥⌘↑ / ⇧⌥⌘↓. La recherche, les filtres et le tri en cours sont respectés. Une flèche se grise quand il n'y a plus rien dans sa direction. Avec le filtre Lignes à traiter, les deux flèches sont grisées : ce filtre ne montre que des lignes incomplètes.
  • Refuser une ligne vide les champs auto-complétés de l'appareil, et l'import ne les réécrira plus (sauf si le fichier lui-même porte la valeur).
  • Bouton vert « Tout valider » : valide tout d'un coup, après une confirmation qui rappelle la confiance des sources. Une validation en masse ne s'annule pas.
  • Dans le tableau : clic sur la coche d'une case auto-complétée (vérifie toute la ligne : Type et Fabricant), ou clic droit → Marquer comme vérifié sur les lignes sélectionnées. Corriger une valeur en italique la vérifie aussi.

Règles de nomenclature

Les fabricants codent le type dans leurs références (Bosch S… = lave-vaisselle, Gaggenau BS… = four vapeur…). Une règle de nomenclature dit : « pour cette marque (ou ce groupe de marques), une référence de ce motif est un… ». Une règle validée propose le type ; rien n'est écrit sans votre accord.

  • Données → Règles de nomenclature… : la liste des règles, filtrable par marque ou groupe, motif (mêmes jokers que les filtres de colonne), type, statut (proposée, validée, rejetée), source. Changeraient des appareils ne garde que les règles qui contredisent au moins un type en base ; Pureté ≥ 98 %, celles dont 98 % des appareils ont déjà le type de la règle.
  • La fiche d'une règle (à droite) donne ses mesures (appareils couverts, d'accord), sa source, une note et des exemples, désaccords d'abord. Un bandeau jaune signale une règle trouvée sous une zone grise : son préfixe mélange plusieurs types, une erreur systématique peut s'y cacher (comme les Whirlpool AKP longtemps typés « Four vapeur ») — vérifiez une source avant de la valider.
  • Valider, Rejeter, Remettre en proposée : sur une règle ou sur plusieurs règles sélectionnées (avec un récapitulatif). Les types proposés se recalculent aussitôt, en arrière-plan : la fenêtre reste utilisable.
  • Chercher de nouvelles règles : l'outil cherche dans les données les préfixes qui donnent presque toujours le même type. Les règles trouvées arrivent en statut proposée : elles ne proposent aucun type tant que vous ne les avez pas validées. Un motif déjà tranché par une règle validée ou rejetée n'est pas reproposé.
  • Revoir les types proposés (ou le bouton vert d'eau Types proposés (N) sous le tableau) : la fenêtre de revue, regroupée par règle, comme celle des suggestions (✓ / ✗ / ·, raccourcis V, R, U, Espace). Le panneau de droite montre la règle, sa source et les signaux : deuxième référence d'accord, vote des pièces, libellé d'origine.
  • Accepter en groupe (ligne de groupe, sélection) n'est possible que pour les propositions fortes et pour celles d'une règle validée sur une source web. Les autres s'acceptent une par une ; un bandeau le rappelle. Refuser en groupe est toujours possible.
  • Avant d'écrire, un récapitulatif donne le nombre d'appareils et le comptage par type avant / après. Chaque règle donne une entrée dans l'historique (comme une modification de Type à la main). Un type refusé n'est plus jamais proposé pour cet appareil.
  • Annuler : onglet Acceptations de la fenêtre des règles, Annuler cette acceptation. Le type d'avant revient sur les appareils encore au type accepté ; un appareil modifié depuis est laissé tel quel.
  • À l'import, une règle validée type les appareils sans type et propose un type quand le fichier la contredit (voir Ce que l'import complète tout seul).
  • Dans le tableau, la cellule Type d'un appareil concerné est teintée vert d'eau ; sa bulle dit le type proposé et la règle. Clic droit → Accepter / Refuser le type proposé. Raccourcis des flèches : ⇧⌥⌘ Page préc. / ⇧⌥⌘ Page suiv.

Relations entre références

À l'import d'un seul fichier

  • Section Succession : « Cette réf. remplace », « est remplacée par » et « est équivalente à ». Plusieurs références sont possibles (séparées par un espace), sauf pour « remplacée par » : une pièce n'a qu'une seule remplaçante.

Référence associée (Whirlpool, Indesit, Beko)

  • Quand la pièce importée a une référence Whirlpool (48 suivi de 10 chiffres), Indesit (C00 suivi de 6 chiffres) ou Beko (10 chiffres commençant par 17, 18, 28, 29, 42 à 49, 57 à 59, 61, ou par 151, 190, 191, 244 à 249, 270, 271, 917 à 919, ou 9 chiffres commençant par 16 ou 26), le champ Réf. associée apparaît à droite de la référence : sur la ligne « Réf. » pour un fichier seul, à côté de la référence de chaque carte pour plusieurs fichiers ou un lot de fiches du site. Indiquez la référence jumelle de l'un des deux autres groupes (« 481073071153 » ↔ « C00319033 »). Le champ est facultatif : laissé vide, rien n'est retenu. Vous pouvez aussi y glisser une référence (tuile « Non groupées », autre champ) au lieu de la taper.
  • Référence de forme inconnue (une Beko comme « 210480241 » ou « S210480241 », qui ne ressemble à aucun de ces formats) : un lien Associer… apparaît à la place du champ. Il ouvre le choix Whirlpool / Indesit / Beko ; une fois le groupe choisi, le champ Réf. associée s'affiche comme pour les autres. De même, si la réf. associée saisie a une forme inconnue, une liste Groupe ? apparaît à sa droite pour indiquer son groupe. Le groupe choisi est retenu à l'import, avec la paire : l'application ne le redemandera plus pour cette référence.
  • La référence associée devient une équivalente de la pièce. Dans la Fiche complète, elle s'écrit à la suite de la référence principale, sur la ligne du code produit (« Code produit : C00138863 482000029398 »), et non dans les références équivalentes. La principale vient toujours en premier, que vous recherchiez l'une ou l'autre. Au prochain import de la même pièce, le champ est déjà rempli.
  • Pour une fiche du site, la ligne est remplie d'office avec la 2ᵉ référence de son code produit.
  • Fiche du site : sur les lignes « Remplace les références » et « Références équivalentes », une référence Whirlpool, Indesit ou Beko suivie d'une référence d'un autre de ces groupes est sa jumelle (« 480132102633 C00323671 », ou « 93467637 72X0079 C00316028 481246688999 » au milieu d'autres marques). Les références qui se suivent sont liées deux par deux, dans l'ordre, chaque paire devenant référence associée et équivalente. Si une série a un nombre impair de références, ou deux références du même groupe côte à côte, elle n'est pas liée du tout. Une référence qui a déjà une associée (ou « aucune ») la garde. La fenêtre d'import liste les paires dans la section Succession, sous les champs « remplace » et « équivalente à » (bouton Paires de réf. associées sous les champs de chaque carte d'un lot) : décochez une paire pour ne pas la lier ; les paires déjà liées, en conflit ou non liées y sont montrées avec leur raison.
  • ⇄ Inverser : quand la référence importée n'est pas la principale (le PDF porte le nom de la référence Indesit, mais la principale est la Whirlpool), cliquez ⇄ entre la référence et la référence associée. La référence associée devient la principale de la paire (elle vient en premier dans le code produit), mais les appareils et le libellé restent sur la référence du nom de fichier, qui devient son associée. Un second clic revient au point de départ. (Collage et fiche du site : inchangé, la référence saisie ou le code produit change.)

À l'import de plusieurs fichiers

  • Remplacée par, sur chaque carte de fichier : la remplaçante directe de ce fichier (une seule réf ; du lot, de la base, ou nouvelle — elle est alors créée en fantôme). La case Obsolète se coche d'office.
  • Lignées de succession (bleu) : glissez les anciennes références dans une lignée et indiquez sa courante, la réf la plus récente. Les anciennes deviennent obsolètes. Double-clic sur une réf de la lignée pour en faire la courante.
  • Raccord automatique : un fichier qui a déjà une remplaçante sur sa carte peut être glissé tel quel dans la lignée. C'est sa remplaçante qui est reliée à la courante, et l'étape intermédiaire est conservée (ex. 2808540500 → C00904139 → C00904134). Ces tuiles portent une icône de lien ; l'infobulle indique « via … » ou « direct ».
  • Double-clic sur la pastille « Remplacée par » d'une carte : la réf devient la courante de la lignée qui contient ce fichier (à défaut, de la première lignée sans courante). Rien n'est écrasé si toutes les lignées ont déjà une courante.
  • Glisser-déposer : une tuile se dépose sur un champ « Remplacée par » (elle y est copiée, et remplace la réf déjà saisie) ; une pastille de ce champ se glisse vers une lignée ou un groupe. Dans « Non groupées », ⌘ ou Maj + clic sélectionne plusieurs tuiles à glisser ensemble.
  • Réfs hors lot : « + ajouter des réfs hors lot… » au bas d'un cadre, pour une réf sans fichier (déjà en base ou nouvelle). Elle apparaît en italique avec un « + ».
  • Groupes d'équivalence (violet) : glissez les références interchangeables dans un même groupe. Remplacement et équivalence restent distincts : une réf remplacée devient obsolète, une réf équivalente reste valide.
  • Équivalence entre zones : cochez « Équivalente » sur plusieurs lignées ou groupes ; une référence de chaque zone cochée (la courante d'une lignée, la première réf d'un groupe) est déclarée équivalente aux autres. Il faut au moins deux zones cochées portant une référence.
  • Arbre des remplacements : sous les cadres, il montre en direct ce qui sera enregistré, avec la courante en racine ; « hors lot » signale les réfs sans fichier.
  • Le récapitulatif en bas indique ce qui sera réellement créé. Une alerte orange signale une déclaration sans effet, ou une contradiction qui bloque l'import : une réf qui aurait deux remplaçantes, ou une boucle (A → B → A).

Dans le gestionnaire de pièces

  • Sélectionnez une pièce : le panneau de droite affiche ses équivalences, ce qu'elle remplace et ce qui la remplace.
  • Ajouter une relation sans ouvrir de fenêtre : chaque carte a un champ de saisie, comme à l'import. Tapez une référence (la liste propose celles de la base) puis Espace ou Entrée, ou collez-en plusieurs d'un coup : elles sont enregistrées aussitôt et apparaissent dans la carte. Une ligne verte dit ce qui a été fait (« ✓ 2 ajoutées · X91 créée (fantôme) ») ; une erreur s'affiche en rouge. Une référence inconnue est créée en fantôme ; la croix de sa puce annule. Quitter le champ n'enregistre rien.
    • Remplacée par : une seule référence. Si la pièce a déjà une remplaçante, une confirmation est demandée avant de la changer.
    • Avec plusieurs pièces sélectionnées, « Remplacée par » s'applique à toutes ; « Remplace » est désactivée (une référence n'a qu'une remplaçante) ; « Équivalences » lie la pièce affichée.
  • Le bouton + d'une carte ouvre la fenêtre de sélection, pour chercher par libellé ou parcourir : en haut, les références choisies (une croix retire, on peut aussi y taper ou coller) ; en dessous, Rechercher filtre le tableau par référence ou libellé sans jamais vider le choix. Double-clic ou Entrée sur une ligne l'ajoute (elle reste affichée, « Ajoutée ») ; une référence inconnue est signalée (« sera créée en fantôme »). Ajouter N références (ou ⌘Entrée) valide. Le texte déjà tapé dans le champ de la carte sert de recherche.
  • Réf. associée : pour une pièce Whirlpool, Indesit ou Beko, la ligne Réf. associées en tête de la carte « Équivalences » montre la paire dans l'ordre du code produit : Principale puis Associée, chaque référence avec son rôle ; la pièce affichée est grisée « (cette pièce) ». La jumelle n'est pas répétée dans la liste des équivalences en dessous.
    • + choisit la référence associée ; Aucune retient que la pièce n'a pas de jumelle (l'import ne la demandera plus, la croix efface cette réponse).
    • ⇄ inverse les rôles : l'associée devient la principale et vient en premier dans le code produit.
    • La croix retire la référence associée ; les deux pièces restent équivalentes.
    • Une référence en italique est proposée par la fiche du site (2ᵉ référence du code produit) : la coche verte la confirme, la croix la refuse (elle reste équivalente).
    • Avec deux pièces sélectionnées de groupes différents, Lier comme réf. associées les lie : la pièce affichée devient la principale.
    • Dans la Fiche complète, la jumelle se range sur la même ligne que sa principale : dans le code produit si la principale est la pièce vendue sur le site, sur la ligne de « Références équivalentes » de la principale si celle-ci est une équivalente, dans « Remplace les références » si c'est une ancienne référence.
    • Pièce dont la forme n'est pas reconnue : la ligne indique « forme non reconnue » ; Déclarer son groupe… la déclare Whirlpool, Indesit ou Beko, et la réf. associée se gère alors comme pour les autres. Un groupe déclaré est rappelé à côté (« Beko (déclaré) ») ; sa croix l'oublie.
    • Dans la fenêtre de choix (+), une référence de forme inconnue n'apparaît que si vous la cherchez ; une fois choisie, son groupe vous est demandé avant le lien.
    • Refusés, avec un message : deux références du même groupe, une référence absente des pièces, ou une référence qui a déjà une autre jumelle (retirez d'abord ce lien).
  • Glisser une référence d'une carte vers une autre l'y ajoute (par exemple une ancienne référence de « Remplace » vers « Équivalences ») : la carte visée s'entoure de pointillés bleus, et la référence reste aussi dans sa carte d'origine. Un clic simple sur une référence la recherche, comme avant.
  • Raccourcis : ⌘1, ⌘2, ⌘3 placent le curseur dans la saisie de « Équivalences », « Remplace », « Remplacée par » ; ⌘F dans la recherche ; Échap efface une saisie en cours.
  • Retirer une pièce de son groupe d'équivalence défait aussi sa paire de références associées. Avec plusieurs pièces sélectionnées, Retirer du groupe les retire toutes (la confirmation les liste).
  • Filtres en haut : orphelines, fantômes, sans libellé, obsolètes, remplacées, remplaçantes, équivalentes, libellés incohérents, jumelle à renseigner (pièces Whirlpool, Indesit ou Beko, hors fantômes, sans réf. associée ni réponse « Aucune » — pour les traiter à la suite).
  • Modifier la pièce : la case « Appliquer aussi ce libellé » recopie le libellé sur toute la famille (anciennes et nouvelles références, équivalentes). Les libellés qui seront remplacés sont affichés en orange ; la fenêtre s'agrandit pour tout montrer.
  • Cmd+Clic pour sélectionner plusieurs pièces et appliquer une action groupée.

Reprendre les fiches du site

Une fiche du site s'importe comme un PDF ou un CSV : la fenêtre d'import habituelle, sans question. Orthographe des marques et des types alignée sur la base, type complété d'après les appareils de même référence, puis récapitulatif dans l'historique et boutons Suggestions à valider et Auto-complétés à vérifier (voir Éditer le tableau). Un appareil est reconnu par sa marque et sa référence ; un champ vide est complété, une valeur de l'outil n'est jamais écrasée. Deux entrées, dans le menu Données : Lire une fiche du site… pour une fiche, Importer les fiches du site… pour toutes les fiches, lot par lot (un lot est un import de plusieurs fichiers, une carte par fiche).

Lire une fiche du site

  • Menu Données → Lire une fiche du site… : une seule zone, où vous collez le lien de la page publique ou la description de la fiche (HTML du back-office ou texte), puis Lire. Un lien seul est téléchargé ; tout autre texte est lu comme la description. Raccourci : copiez le lien d'une fiche de 1001pieces.com et faites Cmd+V dans le tableau, la fiche est lue aussitôt.
  • La fenêtre d'import habituelle s'ouvre, comme pour un PDF. En haut, ce que l'import fera des appareils de la fiche : déjà liés à la pièce, connus à relier, à créer, couverts par une ancienne référence, non importés (appareil à choisir parmi plusieurs, référence illisible, marque inconnue).
  • Référence de pièce : le code produit de la fiche. Une fiche sans code produit demande de la saisir : son libellé est repris pour savoir de quelle pièce il s'agit, et un lien ouvre la fiche sur le site pour trouver la référence.
  • Libellé : celui de l'outil, ou le titre de la fiche sans le type d'appareil pour une pièce nouvelle (« Pompe de vidange R2.5Y »). Modifiez-le au besoin.
  • Succession : les anciennes références et les équivalentes lues sur la fiche. Retirez une référence erronée, ajoutez-en une, ou déplacez-la d'une zone à l'autre si la fiche était mal rangée (une ancienne référence citée en équivalente va dans « Remplace »). Une équivalente supprimée est écartée et ne vous sera plus proposée : l'import vous le fait confirmer (Écarter et importer ou Revenir au dialogue). Une référence seulement déplacée n'est pas écartée.
  • Importer : comme après tout import, le récapitulatif va dans l'historique, et les boutons Suggestions à valider et Auto-complétés à vérifier apparaissent si besoin. La pièce s'affiche ensuite dans la recherche. Relire une fiche déjà importée n'ajoute rien.
  • Fiche à refaire depuis les PDF : une fiche aux données en vrac (nom commercial mêlé d'une description comme « ARG8612 Réfrigérateur 1 porte », n° d'article collé, mot coupé, en-tête de série pris pour une marque) ne crée aucun appareil bancal. Un bandeau orange le signale : les appareils connus sont reliés, les autres ne sont pas créés. Si au moins 20 % des appareils à créer sont douteux, aucun n'est créé. La référence de la pièce est notée « à refaire » dans l'historique : cherchez ses PDF et importez-les. Un import PDF, CSV ou collage de cette référence la retire de la liste.

Importer les fiches du site, par lots

  • Exports : deux fichiers CSV de la base PrestaShop (séparateur ;, triés par id_produit). Le premier contient les produits avec leur description, le second les compatibilités (la table complète, et pas seulement la 1re page affichée sur le site). Ils sont proposés par défaut depuis data/reprise_site/ ; validez-les par Utiliser ces exports.
  • Export plus récent : si ce n'est pas l'export de l'import en cours, choisissez Repartir de zéro ou Continuer l'import après le dernier produit importé.
  • Avancement : dernier produit importé, lots enregistrés, fiches mises de côté, fiches à refaire. Vous pouvez fermer la fenêtre ou l'application à tout moment : l'import reprend au lot suivant.
  • Lire le lot suivant : 100 fiches par défaut (réglable), sans figer la fenêtre ; Arrêter interrompt. La fenêtre d'import s'ouvre ensuite avec une carte par fiche : sa référence de pièce (à saisir s'il n'y a pas de code produit), son libellé, Obsolète, ce que deviennent ses appareils, ses relations (Remplace, Équivalentes, Remplacée par : retirez une référence erronée, ajoutez-en une) et un lien vers la fiche sur le site. En haut, le total du lot et les fiches à refaire.
  • Décochez une carte pour mettre la fiche de côté : rien n'est écrit pour elle, elle revient avec Fiches mises de côté. Une fiche sans code produit n'est importée que si vous saisissez sa référence.
  • Importer : tout le lot en une fois, comme un import de plusieurs fichiers. Le dernier produit importé n'avance qu'une fois le lot écrit en entier : après une interruption, relisez le lot, rien n'est doublé. Fermer la fenêtre d'import sans importer n'écrit rien.
  • Exporter vers EveryParts… (aussi dans le menu Données → Exporter les fiches reprises (EveryParts)…) : la liste des produits du site repris, avec leur référence produit (celle de la page, par exemple « GAU11051894 »), leur n°, leur pièce, la date de reprise et la date d'export. Par défaut, ceux à exporter (jamais exportés, ou relus depuis) ; « Tous les produits repris » montre le reste, et la recherche filtre. Sélectionnez des lignes (sans sélection : toute la liste), puis Exporter. Chaque produit est exporté au format CSV EveryParts de la Configuration des exports : sa référence produit en 1re colonne, et les appareils de la pièce et de ses anciennes références, comme sur la fiche du site. Un fichier par produit, ou Un seul fichier pour toute la sélection. Le dossier est celui des exports (Changer… pour un autre), et Ouvrir le dossier le montre.
  • Fiches à refaire (N) (aussi dans le menu Données → Fiches du site à refaire…) : la liste des fiches en vrac, avec la référence de la pièce, le n° du produit, la raison et des exemples. Ouvrir la page du site, Fait (retire la fiche de la liste), Exporter en CSV… pour chercher les PDF hors de l'outil. Un import PDF, CSV ou collage de la référence la retire d'office.

Importer depuis Agora

Pour une pièce vendue par un constructeur présent chez Agora (Whirlpool, Electrolux, BSH, Miele, Beko, Liebherr, Candy…), les appareils compatibles et le prix se lisent directement chez Agora, sans télécharger de PDF. Menu Données → Importer depuis Agora….

  1. Fichiers MySpace (une fois, puis à chaque nouvel envoi) : téléchargez sur myspace2.agoraplus.com les fichiers Parts_N et Products_N de chaque constructeur, puis Charger les fichiers MySpace… et choisissez leur dossier (zip ou txt, une vingtaine de secondes). Ils donnent, sans consommer d'appel : la référence la plus récente d'une pièce, celles qu'elle remplace, sa désignation, si elle est commandable, et la marque et le type des appareils.
  2. Chercher une référence de pièce : la fenêtre affiche la référence à publier (la plus récente commandable), les références qu'elle remplace, et ce que l'outil et le site connaissent déjà de cette famille. Une pièce qui renvoie au code « article épuisé » de Whirlpool est signalée. Une référence absente des fichiers peut quand même être interrogée en choisissant le constructeur.
  3. Interroger Agora : appareils compatibles et prix de la référence à publier. Prix de vente TTC proposé = prix d'achat × 2, arrondi au dixième (Electrolux : prix public − 33 %, puis × 2), et code produit proposé d'après les règles des codes produit : tous deux sont modifiables avant l'import.
  4. Ouvrir l'import : la fenêtre d'import habituelle, comme pour un collage, avec la 3ᵉ colonne des impressions d'Agora (« Description », reconnue comme Notes, modifiable au mapping). Chaque liste d'appareils reste sous la référence pour laquelle Agora l'a donnée : une pièce Beko 4298130200 garde ses appareils, sa jumelle Indesit C00868066 est proposée en Réf. associée (et non en remplacement). Référence, libellé (à relire) et relations sont préremplis ; plusieurs références avec des appareils donnent un import de plusieurs fichiers. Puis, comme après tout import : orthographe alignée, auto-complétion, règles de nomenclature, Suggestions à valider, Auto-complétés à vérifier.

Quota : la licence permet 10 appels par jour pour les appareils compatibles et 10 pour les prix, remis à zéro à minuit UTC (1 h ou 2 h du matin en France). Le nombre restant est affiché ; une pièce déjà interrogée ne consomme plus rien (réponses gardées en cache). Quota atteint, ou pièce inconnue d'Agora : importez le PDF, comme avant.

Fiche PrestaShop et Cogilog

Une fois la pièce importée, recherchez-la puis Données → Fiche PrestaShop et Cogilog…. La fenêtre réunit ce que donnent les boutons Titre, Fiche complète, Méta Title et Méta Desc (gabarits par défaut), le code produit et le prix venus d'Agora, une catégorie du site proposée d'après le libellé et le type, et le fabricant du site. Tout reste modifiable. Ajouter aux fichiers du jour écrit la fiche dans deux fichiers du dossier des exports : fiches_prestashop_AAAAMMJJ.csv (import CSV de PrestaShop, fiche inactive en attendant la photo) et fiches_cogilog_AAAAMMJJ.csv (matrice d'import Cogilog). Une fiche ajoutée deux fois remplace sa ligne. Les compatibilités partent toujours par Exporter CSV (EveryParts).

Les gabarits du nom et de la description se choisissent dans la fenêtre (gabarit par défaut proposé).

Créer sur PrestaShop : avec le webservice configuré, la fenêtre lit le site (catégories, fabricants, caractéristiques) et dit si une référence de la famille y a déjà une fiche ; la recherche d'Importer depuis Agora fait le même contrôle. Le bouton crée la fiche désactivée, avec la cover par défaut (data/cover_par_defaut.jpg), la catégorie, le fabricant, le prix HT, les métas et les caractéristiques « Type d'appareil » et « Type de pièce » (proposé d'après le libellé, sinon d'après la catégorie). Un code déjà présent sur le site est refusé. Les compatibilités partent toujours par Exporter CSV (EveryParts). En production, une confirmation est demandée. Configuration : fichier data/prestashop.env (lignes PS_URL=… et PS_KEY=…, jamais versionné), clé du webservice en lecture sur les référentiels, en ajout et modification sur les produits et les images.

Code produit : calculé sur la référence la plus récente par les Règles des codes produit (menu Données) : constructeur Agora, motif de la référence (jokers * et ?), texte retiré au début, préfixe ; la première règle qui s'applique l'emporte, une zone de test montre le résultat. Par défaut : C00 + 6 chiffres → SCS + 6 chiffres (Whirlpool ou Beko), Electrolux EL, BSH GAU sans le 00 de tête, Miele MIE, Beko BEO, Liebherr LH, Candy ROS, Whirlpool sans préfixe. Les règles modifiées sont dans data/regles_codes.json. Le code relie l'article Cogilog à la fiche PrestaShop : vérifiez-le. Les catégories proposées viennent de data/categories_site.json, régénéré par scripts/categories_site.py depuis l'export des produits du site.

Clé d'API : fichier data/agora.env, une ligne AGORA_KEY=… (jamais versionné). Cache, compteur et fichiers MySpace sont rangés dans data/agora.db, à part de la base des appareils.

En préparation

  • Libellé de la réf. associée à l'import : la jumelle créée par l'import hérite du libellé de la pièce (ou l'inverse), comme les autres références liées ; un libellé déjà présent n'est jamais écrasé.
  • Fiche complète : une jumelle suit sa principale parmi les équivalentes : une référence équivalente qui est la jumelle (réf. associée) d'une autre est rangée juste derrière elle, et la paire se classe avec la lignée de sa principale (successeur avant ancienne référence), au lieu d'être éclatée par nombre d'appareils. Ex. Beko : C00916410 4298130100 C00880446 4298130172 …
  • ⇄ à l'import d'un fichier : les appareils restent sur le fichier : pour un PDF ou un CSV nommé d'après sa référence, ⇄ fait de la référence associée la principale de la paire, sans plus déplacer les appareils : ils restent sur la référence du nom de fichier (le champ passe de « Réf. associée » à « Réf. principale »). Avant, ils partaient sur l'associée, et la recherche de la référence du fichier ne les montrait plus.
  • Créer l'appareil cherché, et le voir : une référence tapée dans un filtre et absente de la base se crée d'un clic sur Créer l'appareil « … » (sous « Aucun résultat ») ou par Cmd+N, avec la marque et le type filtrés s'ils existent. Toute ligne ajoutée par Cmd+N pendant une recherche apparaît en tête du tableau, sur fond pêche, jusqu'au prochain changement de recherche ou de filtre.
  • Importer depuis Agora (menu Données) : une référence de pièce, sa famille lue dans les fichiers MySpace (référence à publier, références remplacées, déjà dans l'outil ou sur le site), puis ses appareils compatibles et son prix lus chez Agora, sans PDF. La fenêtre d'import habituelle s'ouvre ensuite, référence, libellé et « Remplace » préremplis. Quota de 10 appels par jour affiché et respecté, réponses gardées en cache.
  • Fiche PrestaShop et Cogilog (menu Données) : nom, description, métas, code produit, prix, catégorie et fabricant de la pièce recherchée, gabarits au choix, ajoutés aux fichiers d'import du jour (PrestaShop et Cogilog).
  • Créer sur PrestaShop (fenêtre Fiche PrestaShop et Cogilog) : la fiche est créée sur le site en un clic, désactivée avec la cover par défaut ; contrôle des fiches déjà présentes sur le site dès la recherche Agora.
  • Règles des codes produit (menu Données) : les règles qui proposent le code produit d'une fiche nouvelle, modifiables et testables.

Problèmes d'import

  • Vérifiez l'encodage du fichier CSV (UTF-8 recommandé) et qu'il compte au moins 2 colonnes.
  • Si la première ligne contient des noms de colonnes, cochez « 1ʳᵉ ligne = en-têtes ».
  • Si les colonnes sont mal reconnues, ouvrez « Adapter le mapping » sous l'aperçu.
  • Une alerte surlignée en jaune dans l'historique (ex. pages vides d'un PDF) explique ce qui a été ignoré et pourquoi.

Revenir en arrière

  • Cmd+Z annule les dernières modifications du tableau.
  • Une copie de la base est faite automatiquement avant chaque nettoyage de doublons et avant un import (au plus une par 24 h). Les 2 dernières sont gardées, plus 2 copies faites avant des opérations exceptionnelles.
  • Configuration → Restaurer une sauvegarde… remet une copie en place (l'application se ferme ensuite ; relancez-la).

Installer l'application sur un autre poste

1. Créer l'export (sur le poste d'origine)

  1. Configuration → Exporter l'application…
  2. Choisissez le système du poste cible : Windows ou macOS.
  3. Choisissez un dossier de destination (Bureau recommandé) dans la fenêtre qui s'ouvre, puis cliquez sur Choisir.
  4. Patientez 2 à 3 minutes. Une archive 1001pieces_export_windows_AAAAMMJJ_HHMM.zip (ou …_macos_…) est créée, environ 350 Mo.

L'archive contient l'application, la base de données la plus récente, ce guide et les fichiers de test d'import. Les sauvegardes et les journaux restent sur le poste d'origine. Envoyez l'archive par un service de transfert de gros fichiers ou une clé USB.

2. Sur un PC Windows (10 ou 11, 64 bits)

Rien à installer : Python et tout le nécessaire sont dans l'archive.

  1. Si l'archive a été téléchargée : clic droit sur le .zip → Propriétés → cocher Débloquer → OK.
  2. Clic droit sur le .zip → Extraire tout… → choisir un dossier court (ex. C:\1001pieces ou Documents).
  3. Dans le dossier extrait, double-clic sur 1001pieces_autofill.bat.
  4. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même (une seule fois).
  5. Raccourci sur le Bureau : clic droit sur 1001pieces_autofill.bat → Envoyer vers → Bureau (créer un raccourci).
Ne lancez pas l'application depuis l'intérieur du .zip : extrayez-le d'abord. Si l'application ne s'ouvre pas, lancez 1001pieces_autofill_console.bat : une fenêtre noire affiche le message d'erreur.

3. Sur un Mac

Prérequis : un Mac du même type que celui qui a fait l'export (Apple Silicon ou Intel) et la même version de Python, indiquée dans la fenêtre d'export et dans README_INSTALL.md (par exemple 3.13). Si elle manque : brew install python@3.13 ou l'installeur de python.org.

  1. Double-clic sur le .zip pour l'extraire.
  2. Double-cliquez sur install.command : trouve le bon Python, débloque le dossier et installe les dépendances (une seule fois). S'il ne trouve pas le bon Python, il l'indique et dit comment l'installer ; relancez-le ensuite.
  3. Double-cliquez sur 1001pieces_autofill.app : lance l'application.
Si l'application ne s'ouvre pas, lancez 1001pieces_autofill_console.command : une fenêtre Terminal affiche le message d'erreur.
Aucune connexion internet n'est nécessaire sur le poste cible, ni sous Windows ni sous macOS. Chaque poste travaille ensuite sur sa propre copie de la base : les modifications ne se synchronisent pas entre postes.

Assistance

En cas de problème, consultez les logs via Journal dans la barre d'outils (ou F12). Les fichiers sont aussi dans le dossier data/logs de l'application.
