Guide d'utilisation — 1001pieces.com

Démarrage rapide

Import de données

  1. Import de fichiers : bouton Import dans la barre d'outils, ou glisser/déposer un CSV ou PDF sur le tableau
  2. Fenêtre de relations (import multi-fichiers) : déclarez les lignées de succession et les groupes d'équivalence en glissant/déposant les références (bleu = succession, violet = équivalence)
  3. Collage : copiez des données depuis Excel/Calc et collez avec Cmd+V
  4. Référence de pièce : lors de l'import, la référence de pièce est automatiquement remplie avec le nom du fichier

Navigation et édition

  • Double-clic sur une cellule pour l'éditer
  • Entrée : valider et descendre à la cellule suivante
  • Suppr / Retour arrière : effacer les cellules sélectionnées

Gestion des pièces

  • Gestionnaire de pièces : accessible via Gestion → Pièces
  • Sélection multiple : Cmd+Clic pour sélectionner plusieurs pièces

Fonctionnalités avancées

  • Glisser/Déposer : déposez des fichiers CSV directement sur le tableau
  • Auto-complétion : champs vides complétés automatiquement via Action → Autocomplétion
  • Recherche avancée : utilisez && (ET) et || (OU) dans la barre de recherche
  • Supersession : gérez les références obsolètes et leurs successeurs via la bannière d'information

✨ Nouveautés v3.58.0

Relations par groupes à l'import multi-fichiers

Déclarez les lignées de succession et les groupes d'équivalence directement pendant l'import. Une fenêtre dédiée vous permet de :
  • Glisser-déposer les références entre colonnes (Succession à gauche, Équivalence à droite)
  • Promouvoir une référence en « Courante » : soit en la glissant vers le haut, soit en double-clic
  • Visualiser les groupes complets : la colonne « Toutes équivalentes » affiche automatiquement toutes les références du groupe
  • Dérivation automatique : les obsolescences se déduisent du graphe (si A → B → C courant, alors A et B sont marquées obsolètes)
Ces relations sont enregistrées dans la table de supersession et visibles dans le tableau principal via la bannière (bleu pour succession, violet pour équivalence).

Suggestions Type/Marque par similarité

Lors de l'import, les appareils dont le Type ou la Marque est absent reçoivent automatiquement une suggestion basée sur la similarité de référence (variantes de suffixes, fuzzy matching, consensus de préfixe) :
  • Indicateur visuel : les cellules Type/Marque proposées affichent une icône magique (✨) et un fond clair
  • Validation utilisateur : cliquez sur la cellule proposée pour voir tous les candidats, score de similarité, et choisir l'un d'eux
  • Bannière informative : un compteur indique le nombre d'appareils en attente de validation
  • Protection contre le « rebadging » : les suggestions sur préfixe numérique (codes génériques, beaucoup de marques différentes) sont désactivées par défaut
  • Annulation manuelle : si vous éditez Type ou Marque manuellement, l'indicateur disparaît automatiquement

Dépannage

Problèmes d'import

  • Vérifiez l'encodage du fichier (UTF-8 recommandé)
  • Assurez-vous que le fichier CSV a au moins 2 colonnes
  • Première ligne = en-têtes (ignorée lors de l'import)

Performance

  • L'application pagine automatiquement les gros datasets
  • Utilisez les filtres de colonnes pour affiner l'affichage

Déploiement sur une autre machine

Générer le dossier d'export

  1. Menu Gestion → Exporter l'application…
  2. Choisissez un dossier de destination (Bureau recommandé)
  3. Patientez 1-2 minutes (téléchargement des dépendances)
  4. Un dossier 1001pieces_export_YYYYMMDD_HHMM/ est créé

Sur le poste cible (macOS)

Prérequis : Python 3.10+ (python3 --version pour vérifier)

  1. Double-cliquez sur install.command — installe les dépendances (une seule fois)
  2. Double-cliquez sur 1001pieces_autofill.app — lance l'application
Aucune connexion internet nécessaire sur le poste cible (les wheels sont inclus).
