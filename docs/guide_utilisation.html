Guide d'utilisation — 1001pieces.com

Mac ou Windows ? Ce guide écrit Cmd (touche ⌘ du Mac). Sous Windows, utilisez Ctrl à la place : Cmd+S devient Ctrl+S, Cmd+Clic devient Ctrl+Clic, etc. Tout le reste est identique.

Démarrage rapide

Importer des données

  1. Fichiers PDF ou CSV : bouton Importer de la barre d'outils, ou glisser-déposer les fichiers sur le tableau.
  2. Collage : copiez des lignes depuis Excel ou Calc, puis Cmd+V dans le tableau.
  3. Référence de pièce : elle est remplie d'après le nom du fichier ; vous pouvez la modifier et lui donner un libellé avant d'importer.
  4. Aperçu : avant de valider, la fenêtre montre ce qui sera créé. Un encadré « Orthographe alignée sur la base » annonce les marques et types réécrits (ex. MIDEA → Midea, déjà présent en base).
  5. Progression : une ligne par étape (extraction, finalisation, suggestions…) avec sa durée.
  6. Plusieurs fichiers : un appareil créé par un fichier et cité par un fichier suivant du même import est relié aux deux pièces dès le premier import.
Pour essayer sans risque : le dossier fichiers_test_import, livré avec l'application exportée, contient quelques PDF et un CSV d'exemple.

Ce que l'import complète tout seul

  • Auto-complétion : un appareil importé sans Type ou sans Fabricant reçoit celui d'un appareil de même référence déjà en base. Un appareil existant dont le Type ou le Fabricant est vide est complété de la même façon ; une valeur déjà saisie n'est jamais écrasée.
  • Le bouton Données → Autocomplétion applique exactement la même règle aux lignes affichées : une valeur auto-complétée pas encore vérifiée ne sert pas de modèle, une valeur refusée n'est pas reproposée, et ce qu'il complète apparaît dans Auto-complétés à vérifier comme après un import.
  • Ces valeurs déduites s'affichent dans le tableau en italique, sur fond lavande, avec une coche bleue à droite de la case ; le numéro de la ligne passe en orange gras sur fond orange pâle. Ces repères restent jusqu'à la vérification (voir Vérifier les auto-complétés ci-dessous).
  • Suggestions : quand rien ne permet de déduire la valeur, l'import propose un Type / une Marque d'après des références proches, ou le type que portent déjà les appareils de la pièce. Rien n'est écrit sans votre validation (voir ci-dessous).

Retrouver les appareils d'une pièce

  • Tapez la référence dans Recherche par pièce (sous le tableau, ou au-dessus selon Affichage → Recherche pièce en haut du tableau).
  • Plusieurs références : ref1 || ref2 (OU). Combinaison : ref1 && ref2 (ET).
  • La recherche est exacte par défaut ; le bouton loupe à droite du champ la rend partielle.
  • Si la pièce a été remplacée ou a des équivalences, un bandeau le signale au-dessus du tableau ; il permet d'inclure les anciennes références ou les équivalentes.

Filtres au-dessus du tableau

  • Un champ par colonne. Pour Type et Marque, la flèche déroule la liste complète ; la frappe filtre dès la 1ʳᵉ lettre, sur une partie du mot.
  • Le bouton ✕ (au-dessus de la colonne Pièces) efface tous les filtres.

Panneau de droite

  • Pièces de l'appareil sélectionné. Avec plusieurs appareils sélectionnés : les pièces communes, y compris celles portées sous des références différentes d'une même lignée (mention « ⇄ Commune par lignée »).
  • Ajouter une pièce : bouton +, puis saisie de la référence et du libellé. Entrée ajoute, Échap annule ; la pastille indique à combien d'appareils la pièce sera ajoutée. La pièce ajoutée est surlignée en vert un instant.
  • Historique des opérations : chaque action, avec un badge par type (Modif., Import, Export, Suppr., Erreur, Annul., Pièce, Système). Les 100 dernières entrées sont rechargées à l'ouverture. Les alertes d'import (pages vides d'un PDF, colonnes mal reconnues) sont surlignées en jaune. L'icône ↗ à côté du titre ouvre l'historique complet.
  • Exports : sur la 1ʳᵉ ligne Méta Title, Méta Desc (Maj+clic pour une autre formulation) et Exporter CSV ; sur la 2ᵉ Titre (un tiers) et Fiche complète (deux tiers). HTML Marques et HTML Détails sont repliés sous « ▸ Exports HTML » : un clic déplie ou replie la ligne (mémorisé sur le poste). Les boutons s'activent après une recherche par pièce. Sur Titre, Fiche complète et HTML Détails, la flèche : la survoler ouvre la liste des autres gabarits (par ordre alphabétique ; à partir de 6 gabarits, champ « Filtrer… » et vos 3 gabarits récents en tête) ; cliquer dessus ouvre l'aperçu d'export. Le reste du bouton exporte avec le gabarit par défaut.
  • Aperçu d'export : fenêtre qui montre l'export de chaque gabarit sur la recherche en cours. À gauche l'onglet Rendu (tel qu'affiché sur le site) et l'onglet Code (coloré, indenté) ; à droite, près des boutons, les gabarits (★ = celui du clic sur le bouton, champ de filtre ; les noms longs passent à la ligne, jamais coupés) ; en dessous, caractères, appareils, marques et réduction éventuelle. Copier (ou double-clic sur un gabarit) copie exactement ce qui est affiché, puis ferme la fenêtre pour revenir sur la fenêtre principale ; Par défaut en fait le gabarit du clic sur le bouton ; Modifier le modèle… l'ouvre dans la configuration des exports. Tant que vous ne copiez pas, la fenêtre reste ouverte pendant que vous travaillez et suit les nouvelles recherches ; avec plusieurs références, Actualiser propose de choisir.
  • Titre : copie le titre de la fiche produit, par défaut « libellé pour type marques - référence la plus récente ». Taper une ancienne référence donne le titre de la courante. Jusqu'à 4 marques (les plus représentées) et 120 caractères : au-delà, les dernières marques puis les types en plus sont retirés, jamais le libellé ni la référence. Plusieurs types sont cités quand ils couvrent à peu près autant de modèles. Gabarits réglables dans Configuration des exports, onglet Titre (aperçu en direct ; séparateurs distincts pour les marques et pour les types ; case Varier le nom de l'appareil, décochée par défaut, pour citer « machine à laver » au lieu de « lave-linge » selon l'onglet Appareils, utile pour un gabarit repris dans une description) ; avec plusieurs gabarits, la flèche du bouton propose les autres.
  • Fiche complète : copie tout le code HTML de la fiche produit, dans l'ordre : titre, « Compatible avec » (marques), code produit, « Remplace les références », « Références équivalentes » (chaque équivalente suivie de ses anciennes références, de la plus fournie en appareils à la moins fournie ; à égalité, celles qui commencent par une lettre d'abord), bloc Informations facultatif, puis la liste des appareils. Le code produit est la référence tapée ; une ancienne référence donne la fiche de la courante. Pour une pièce reprise du site, la fiche se réécrit comme sur le site : le code produit garde sa paire (« 481073071153 C00319033 », les anciennes références des deux allant dans « Remplace », dans l'ordre de la fiche du site : « C00535957 488000535957 C00309416 482000032568 »), une ligne « Références équivalentes » par marque d'origine (BSH, Candy…), et les références écartées à la reprise n'apparaissent plus. Sans marque d'origine connue, toutes les équivalentes restent sur une seule ligne. Une ligne sans référence n'est pas écrite. Marques et appareils sont ceux affichés dans le tableau : une recherche inclut d'office les appareils des références équivalentes (bandeau ≡) ; « Voir uniquement … » les retire. La limite (200 000 caractères par défaut) porte sur la fiche entière : au-delà, la liste des appareils est réduite comme pour HTML Détails. Variantes dans Configuration des exports, onglet Fiche : gabarit Titre et profil de liste d'appareils utilisés, texte de chaque ligne, bloc Informations (« Fiche avec informations » l'inclut, à compléter ensuite sur le site).
  • Exporter CSV (EveryParts) : la fenêtre demande la référence d'export, écrite dans la colonne product et dans le nom du fichier. Pour une pièce vendue sur le site, elle propose la référence interne de son produit (« EL1113161010 » pour 1113161010), toujours modifiable ; une ancienne référence propose celle de la pièce courante (00703010 → « GAU11051894 »). Une pièce vendue sous plusieurs produits affiche une liste « Produit du site » pour choisir. Sans produit, la référence recherchée est proposée, comme avant. Dans Configuration des exports, onglet CSV, les variables {ref_interne} et {id_product} (n° du produit sur le site) s'ajoutent aux colonnes et au nom du fichier ; le format par défaut ne change pas.
  • Configuration des exports : le code HTML des modèles est coloré (balises, attributs, valeurs, &nbsp;, variables sur fond jaune) et indenté à l'écran, un bloc par ligne. Ce qui est enregistré et exporté ne change pas : l'indentation n'existe qu'à l'affichage. Entrée passe à la ligne entre deux balises ; l'indentation est refaite en quittant la zone.
  • Configuration des exports, onglets HTML, Titre et Fiche : trois colonnes séparées par des poignées que l'on déplace à la souris. À gauche, la liste des gabarits (profils HTML Détails, gabarits Titre, variantes Fiche) : celui par défaut en tête avec une étoile, les autres par ordre alphabétique, noms longs sur plusieurs lignes ; champ « Filtrer… » dès 6 gabarits ; boutons Nouveau / Dupliquer / Supprimer dessous et toutes les actions au clic droit. Au centre, les réglages, avec en tête le champ Nom (renommer directement ; aussi par double-clic ou F2 dans la liste ; un nom vide ou déjà pris est refusé) et le bouton Par défaut. À droite, l'aperçu. Taille de la fenêtre et largeur des colonnes sont mémorisées par poste. Onglet Fiche : une carte par bloc, dans l'ordre où la fiche est écrite (1 Titre … 7 Liste des appareils) ; listes Titre et Liste des appareils triées, « Gabarit par défaut (nom) » en tête ; « Modifier ce gabarit › » ouvre le gabarit dans son onglet, un bandeau « ‹ Retour à la fiche » ramène à la variante. Un gabarit Titre ou un profil HTML Détails renommé l'est aussi dans les variantes qui l'utilisent.
  • Configuration des exports, onglet Appareils : les autres appellations de chaque type d'appareil dans les textes générés (« machine à laver » pour « lave-linge »). Le type en base garde une part réglable (50 % par défaut) ; les autres appellations actives se partagent le reste. Le choix est fixe pour une référence : régénérer une fiche ne le change pas. En revanche, modifier la liste peut changer le texte des fiches déjà exportées. Texte concerné par défaut : la méta description. Le méta title garde le type en base, sauf si vous cochez sa case. Les titres se règlent gabarit par gabarit, dans l'onglet Titre (case « Varier le nom de l'appareil »). Une appellation qui obligerait à retirer une marque, une référence ou un mot est remplacée par le type en base. À gauche, les types d'appareils et leur genre (pour écrire « un » ou « une ») ; à droite, les appellations du type sélectionné, chacune avec son genre, sa nature et une case Active. Un sous-type (« radiateur », « sèche-serviette » ou « accumulateur » pour « chauffage ») ne correspond qu'à une partie des appareils : il est livré désactivé. En bas, l'aperçu donne la part de chaque appellation par texte, ainsi que l'accord. La colonne Type, les filtres, la recherche et le CSV ne changent pas.

Barre d'état (sous le tableau)

  • Lignes à traiter ▲ ▼ : passe d'une ligne incomplète (Type ou Fabricant manquant) à la suivante.
  • Auto-complétés à vérifier (N) | Tout valider : visible quand des valeurs auto-complétées attendent une vérification (voir plus bas).
  • À droite : l'icône disquette (sauvegarde) et la pastille (connexion à la base) sont vertes quand tout va bien, orange pendant une sauvegarde ou s'il reste des changements non enregistrés. Survolez-les pour lire l'état. Tout à droite, la version de l'application.

Éditer le tableau

  • Double-clic ou F2 sur une cellule pour la modifier. Taper sur une cellule déjà remplie ne la modifie pas : c'est voulu, pour éviter les écrasements accidentels.
  • Entrée : passe à la ligne suivante, même colonne.
  • Suppr / Retour arrière : vide les cellules sélectionnées.
  • Cmd+D : liste des valeurs déjà utilisées dans la colonne (sauf colonnes de référence).
  • Marque et Type : une valeur tapée reprend l'orthographe déjà présente en base (bosch → Bosch).
  • Poignée de recopie (petit carré en bas à droite de la sélection), comme dans un tableur :
    • glisser vers le bas ou vers le haut recopie la valeur (ou le motif de plusieurs lignes) ;
    • double-clic remplit vers le bas les cases vides ; s'il n'y a rien à remplir en bas, il remplit vers le haut.

Valider les suggestions

  • Les cellules avec une suggestion sont teintées ; un clic montre les candidats.
  • Le bouton ambre « Suggestions à valider (N) », sous le tableau à côté des lignes incomplètes, ouvre la fenêtre de validation.
  • Chaque ligne a un état : ✓ validée, ✗ refusée ou · en attente. Les suggestions sûres arrivent validées. Raccourcis : V valider, R refuser, U remettre en attente, Espace bascule ✓ / ·, Entrée ou double-clic pour corriger. Sur une ligne de groupe, la décision vaut pour tout le groupe.
  • Les lignes sont regroupées par preuve (même référence, référence voisine, type de la pièce, autre référence, famille de préfixe) ; les puces du haut filtrent, dont ⚠ À risque. Le panneau de droite détaille la preuve, ce que disent les pièces de l'appareil et les autres candidats (lien Prendre).
  • Autre référence : quand la colonne « Autre référence » porte une désignation déjà vue (« Lave-vaisselle tout-intégrable », « Side by side »…), le Type de la plupart des appareils qui ont ce même texte est proposé (au moins 5 appareils, à 95 % ou plus). C'est un indice, pas une certitude : un fichier peut être mal étiqueté. Seul le Type est proposé, la marque reste à saisir ; si une autre preuve propose un type différent, les deux candidats s'affichent et la ligne n'est pas validée d'office.
  • Appliquer (⌘ Entrée) enregistre sans fermer : on peut traiter une longue liste en plusieurs fois. Une suggestion refusée n'est plus jamais proposée pour cet appareil.

Vérifier les auto-complétés

  • Bouton bleu « Auto-complétés à vérifier (N) » : ouvre la liste, regroupée par import. Tout est validé d'office ; mettez en attente ce qui est douteux, corrigez par double-clic, puis Appliquer. Mêmes raccourcis que pour les suggestions ; le panneau de droite confronte la valeur écrite aux pièces de l'appareil.
  • Refuser une ligne vide les champs auto-complétés de l'appareil, et l'import ne les réécrira plus (sauf si le fichier lui-même porte la valeur).
  • Bouton vert « Tout valider » : valide tout d'un coup, après une confirmation qui rappelle la confiance des sources. Une validation en masse ne s'annule pas.
  • Dans le tableau : clic sur la coche d'une case auto-complétée (vérifie toute la ligne : Type et Fabricant), ou clic droit → Marquer comme vérifié sur les lignes sélectionnées. Corriger une valeur en italique la vérifie aussi.

Relations entre références

À l'import d'un seul fichier

  • Section Succession : « Cette réf. remplace », « est remplacée par » et « est équivalente à ». Plusieurs références sont possibles (séparées par un espace), sauf pour « remplacée par » : une pièce n'a qu'une seule remplaçante.

Référence associée (Whirlpool, Indesit, Beko)

  • Quand la pièce importée a une référence Whirlpool (48 suivi de 10 chiffres), Indesit (C00 suivi de 6 chiffres) ou Beko (10 chiffres commençant par 17, 18 ou 28), le champ Réf. associée apparaît à droite de la référence : sur la ligne « Réf. » pour un fichier seul, à côté de la référence de chaque carte pour plusieurs fichiers ou un lot de fiches du site. Indiquez la référence jumelle de l'un des deux autres groupes (« 481073071153 » ↔ « C00319033 »). Le champ est facultatif : laissé vide, rien n'est retenu.
  • La référence associée devient une équivalente de la pièce. Dans la Fiche complète, elle s'écrit à la suite de la référence, sur la ligne du code produit (« Code produit : C00138863 482000029398 »), et non dans les références équivalentes ; de même en partant de l'autre référence. Au prochain import de la même pièce, le champ est déjà rempli.
  • Pour une fiche du site, la ligne est remplie d'office avec la 2ᵉ référence de son code produit.

À l'import de plusieurs fichiers

  • Remplacée par, sur chaque carte de fichier : la remplaçante directe de ce fichier (une seule réf ; du lot, de la base, ou nouvelle — elle est alors créée en fantôme). La case Obsolète se coche d'office.
  • Lignées de succession (bleu) : glissez les anciennes références dans une lignée et indiquez sa courante, la réf la plus récente. Les anciennes deviennent obsolètes. Double-clic sur une réf de la lignée pour en faire la courante.
  • Raccord automatique : un fichier qui a déjà une remplaçante sur sa carte peut être glissé tel quel dans la lignée. C'est sa remplaçante qui est reliée à la courante, et l'étape intermédiaire est conservée (ex. 2808540500 → C00904139 → C00904134). Ces tuiles portent une icône de lien ; l'infobulle indique « via … » ou « direct ».
  • Double-clic sur la pastille « Remplacée par » d'une carte : la réf devient la courante de la lignée qui contient ce fichier (à défaut, de la première lignée sans courante). Rien n'est écrasé si toutes les lignées ont déjà une courante.
  • Glisser-déposer : une tuile se dépose sur un champ « Remplacée par » (elle y est copiée, et remplace la réf déjà saisie) ; une pastille de ce champ se glisse vers une lignée ou un groupe. Dans « Non groupées », ⌘ ou Maj + clic sélectionne plusieurs tuiles à glisser ensemble.
  • Réfs hors lot : « + ajouter des réfs hors lot… » au bas d'un cadre, pour une réf sans fichier (déjà en base ou nouvelle). Elle apparaît en italique avec un « + ».
  • Groupes d'équivalence (violet) : glissez les références interchangeables dans un même groupe. Remplacement et équivalence restent distincts : une réf remplacée devient obsolète, une réf équivalente reste valide.
  • Équivalence entre zones : cochez « Équivalente » sur plusieurs lignées ou groupes ; une référence de chaque zone cochée (la courante d'une lignée, la première réf d'un groupe) est déclarée équivalente aux autres. Il faut au moins deux zones cochées portant une référence.
  • Arbre des remplacements : sous les cadres, il montre en direct ce qui sera enregistré, avec la courante en racine ; « hors lot » signale les réfs sans fichier.
  • Le récapitulatif en bas indique ce qui sera réellement créé. Une alerte orange signale une déclaration sans effet, ou une contradiction qui bloque l'import : une réf qui aurait deux remplaçantes, ou une boucle (A → B → A).

Dans le gestionnaire de pièces

  • Sélectionnez une pièce : le panneau de droite affiche ses équivalences, ce qu'elle remplace et ce qui la remplace. Les boutons + ajoutent une relation.
  • Filtres en haut : orphelines, fantômes, sans libellé, obsolètes, remplacées, remplaçantes, équivalentes, libellés incohérents.
  • Modifier la pièce : la case « Appliquer aussi ce libellé » recopie le libellé sur toute la famille (anciennes et nouvelles références, équivalentes). Les libellés qui seront remplacés sont affichés en orange.
  • Cmd+Clic pour sélectionner plusieurs pièces et appliquer une action groupée.

Reprendre les fiches du site

Une fiche du site s'importe comme un PDF ou un CSV : la fenêtre d'import habituelle, sans question. Orthographe des marques et des types alignée sur la base, type complété d'après les appareils de même référence, puis récapitulatif dans l'historique et boutons Suggestions à valider et Auto-complétés à vérifier (voir Éditer le tableau). Un appareil est reconnu par sa marque et sa référence ; un champ vide est complété, une valeur de l'outil n'est jamais écrasée. Deux entrées, dans le menu Données : Lire une fiche du site… pour une fiche, Importer les fiches du site… pour toutes les fiches, lot par lot (un lot est un import de plusieurs fichiers, une carte par fiche).

Lire une fiche du site

  • Menu Données → Lire une fiche du site… : une seule zone, où vous collez le lien de la page publique ou la description de la fiche (HTML du back-office ou texte), puis Lire. Un lien seul est téléchargé ; tout autre texte est lu comme la description. Raccourci : copiez le lien d'une fiche de 1001pieces.com et faites Cmd+V dans le tableau, la fiche est lue aussitôt.
  • La fenêtre d'import habituelle s'ouvre, comme pour un PDF. En haut, ce que l'import fera des appareils de la fiche : déjà liés à la pièce, connus à relier, à créer, couverts par une ancienne référence, non importés (appareil à choisir parmi plusieurs, référence illisible, marque inconnue).
  • Référence de pièce : le code produit de la fiche. Une fiche sans code produit demande de la saisir : son libellé est repris pour savoir de quelle pièce il s'agit, et un lien ouvre la fiche sur le site pour trouver la référence.
  • Libellé : celui de l'outil, ou le titre de la fiche sans le type d'appareil pour une pièce nouvelle (« Pompe de vidange R2.5Y »). Modifiez-le au besoin.
  • Succession : les anciennes références et les équivalentes lues sur la fiche. Retirez une référence erronée (une équivalente retirée est écartée et ne vous sera plus proposée), ou ajoutez-en une.
  • Importer : comme après tout import, le récapitulatif va dans l'historique, et les boutons Suggestions à valider et Auto-complétés à vérifier apparaissent si besoin. La pièce s'affiche ensuite dans la recherche. Relire une fiche déjà importée n'ajoute rien.
  • Fiche à refaire depuis les PDF : une fiche aux données en vrac (nom commercial mêlé d'une description comme « ARG8612 Réfrigérateur 1 porte », n° d'article collé, mot coupé, en-tête de série pris pour une marque) ne crée aucun appareil bancal. Un bandeau orange le signale : les appareils connus sont reliés, les autres ne sont pas créés. Si au moins 20 % des appareils à créer sont douteux, aucun n'est créé. La référence de la pièce est notée « à refaire » dans l'historique : cherchez ses PDF et importez-les. Un import PDF, CSV ou collage de cette référence la retire de la liste.

Importer les fiches du site, par lots

  • Exports : deux fichiers CSV de la base PrestaShop (séparateur ;, triés par id_produit). Le premier contient les produits avec leur description, le second les compatibilités (la table complète, et pas seulement la 1re page affichée sur le site). Ils sont proposés par défaut depuis data/reprise_site/ ; validez-les par Utiliser ces exports.
  • Export plus récent : si ce n'est pas l'export de l'import en cours, choisissez Repartir de zéro ou Continuer l'import après le dernier produit importé.
  • Avancement : dernier produit importé, lots enregistrés, fiches mises de côté, fiches à refaire. Vous pouvez fermer la fenêtre ou l'application à tout moment : l'import reprend au lot suivant.
  • Lire le lot suivant : 100 fiches par défaut (réglable), sans figer la fenêtre ; Arrêter interrompt. La fenêtre d'import s'ouvre ensuite avec une carte par fiche : sa référence de pièce (à saisir s'il n'y a pas de code produit), son libellé, Obsolète, ce que deviennent ses appareils, ses relations (Remplace, Équivalentes, Remplacée par : retirez une référence erronée, ajoutez-en une) et un lien vers la fiche sur le site. En haut, le total du lot et les fiches à refaire.
  • Décochez une carte pour mettre la fiche de côté : rien n'est écrit pour elle, elle revient avec Fiches mises de côté. Une fiche sans code produit n'est importée que si vous saisissez sa référence.
  • Importer : tout le lot en une fois, comme un import de plusieurs fichiers. Le dernier produit importé n'avance qu'une fois le lot écrit en entier : après une interruption, relisez le lot, rien n'est doublé. Fermer la fenêtre d'import sans importer n'écrit rien.
  • Exporter vers EveryParts… (aussi dans le menu Données → Exporter les fiches reprises (EveryParts)…) : la liste des produits du site repris, avec leur référence produit (celle de la page, par exemple « GAU11051894 »), leur n°, leur pièce, la date de reprise et la date d'export. Par défaut, ceux à exporter (jamais exportés, ou relus depuis) ; « Tous les produits repris » montre le reste, et la recherche filtre. Sélectionnez des lignes (sans sélection : toute la liste), puis Exporter. Chaque produit est exporté au format CSV EveryParts de la Configuration des exports : sa référence produit en 1re colonne, et les appareils de la pièce et de ses anciennes références, comme sur la fiche du site. Un fichier par produit, ou Un seul fichier pour toute la sélection. Le dossier est celui des exports (Changer… pour un autre), et Ouvrir le dossier le montre.
  • Fiches à refaire (N) (aussi dans le menu Données → Fiches du site à refaire…) : la liste des fiches en vrac, avec la référence de la pièce, le n° du produit, la raison et des exemples. Ouvrir la page du site, Fait (retire la fiche de la liste), Exporter en CSV… pour chercher les PDF hors de l'outil. Un import PDF, CSV ou collage de la référence la retire d'office.

En préparation

  • Reprise des fiches du site : une fiche du site 1001pieces.com s'importe comme un PDF ou un CSV, dans la fenêtre d'import habituelle et sans question. Données → Lire une fiche du site… pour une fiche : une seule zone pour coller son lien ou sa description, ou Cmd+V d'un lien dans le tableau. Données → Importer les fiches du site… pour tout le site, par lots de 100 depuis les deux exports PrestaShop : une carte par fiche (décochée = mise de côté ; sans code produit, libellé repris et lien vers la fiche pour saisir la référence), avancement d'une session à l'autre, relance sans doublon. L'aperçu dit ce que deviennent les appareils ; référence, libellé tiré du titre et Succession sont préremplis (une équivalente retirée est écartée). Puis, comme après tout import : orthographe alignée, auto-complétion du type, Suggestions à valider, Auto-complétés à vérifier, récapitulatif dans l'historique. Un appareil est reconnu par sa marque et sa référence ; les liens gardent leur provenance (description, table du site) ; référence produit, EAN et n° du produit sont retenus.
  • Reprise des fiches du site, prudente : un appareil connu garde ses valeurs (seul un nom commercial vide est complété) ; un appareil retrouvé seulement par son nom commercial n'est pas relié s'il n'a pas la même référence ; une référence présente sous une autre marque du groupe n'est pas créée en double ; une référence illisible ou une marque inconnue de l'outil ne crée rien.
  • Fiches du site à refaire depuis les PDF : une fiche aux données en vrac (nom mêlé d'une description, n° d'article collé, mot coupé, en-tête de série pris pour une marque) ne crée aucun appareil bancal. Elle relie seulement les appareils connus, et sa référence est notée pour que vous importiez ses PDF ; l'import de cette référence la retire de la liste.
  • Lecture des fiches plus juste : « Réf. fabricant : 10/1863-5010 POUR APPAREILS VN606E » donne la référence de la pièce et l'appareil VN606E ; « Références équivalentes Rosières : … » prend Rosières pour marque d'origine ; « Remplace les dimensions » (faute du site) est lu comme « Remplace les références » ; « VF3017 (VF 3017) » donne la référence VF3017 ; « HR 6325 - HR632501 » (Philips) donne le modèle HR632501 ; les cotes « C : - cm » et le type « Four à Pyrolyse » ne sont plus pris pour un appareil ou une marque ; « Référence Brauknecht » (faute) et « Référence Ego » sont lues. Une ligne qui n'est que le nom commercial d'un appareil déjà cité par la fiche n'est plus proposée à la création, et « GE » / « General Electric » ne font qu'une marque.
  • Reprise des fiches du site : le nom d'une pièce tiré du titre de la fiche s'arrête avant « pour <type d'appareil> » (types et appellations de l'onglet Appareils) : « Pompe de vidange R2.5Y pour machine à laver (pièce générique) » donne « Pompe de vidange R2.5Y ». Le type n'est plus répété dans le Titre, les métas et la Fiche complète. Une caractéristique chiffrée qui suit le type est gardée (« Résistance 1900W »).
  • Appellations des appareils : la méta description peut citer l'appareil sous un autre nom, par exemple « machine à laver » pour « lave-linge » ou « plaque de cuisson » pour « plaque ». Le choix est fixe pour une référence. Le méta title et les titres gardent le type en base : une case dans l'onglet Appareils pour le méta title, et une case par gabarit dans l'onglet Titre (pour un gabarit repris dans une description, par exemple). Listes modifiables dans Configuration des exports, nouvel onglet Appareils. « Une hotte », « une plaque » : l'article s'accorde désormais au genre de l'appareil.
  • Fiche complète : « Remplace les références » suit l'ordre de la fiche du site pour une pièce reprise (les paires Whirlpool / Indesit restent côte à côte) ; une pièce sans reprise garde l'ordre actuel.
  • Retour vers le site : la Fiche complète d'une pièce reprise du site reprend sa paire dans le code produit (« 481073071153 C00319033 ») et une ligne « Références équivalentes » par marque d'origine ; les références écartées disparaissent. Relue, une fiche ainsi régénérée n'apporte rien de nouveau. Exporter CSV (EveryParts) propose la référence interne du produit du site (« EL1113161010 »), y compris depuis une ancienne référence, avec un choix si la pièce a plusieurs produits ; variables {ref_interne} et {id_product} pour les colonnes et le nom du fichier.
  • Référence associée Whirlpool / Indesit / Beko proposée à l'import (PDF, CSV, collage, fiches du site), à droite de la référence de la pièce : la référence jumelle, facultative. Elle devient une équivalente de la pièce, dans son code produit, et revient pré-remplie au prochain import. Libellés de la section Succession qui ne sont plus coupés.
  • Export EveryParts des fiches reprises (menu Données, et bouton de « Importer les fiches du site ») : la liste des produits du site repris, à exporter au format EveryParts avec leur référence produit en 1re colonne et les appareils de la pièce et de ses anciennes références ; un fichier par produit ou un seul ; seuls les produits jamais exportés, ou relus depuis, sont proposés par défaut.
  • Import de plusieurs fichiers : un appareil créé par un fichier et cité par un fichier suivant est relié aux deux pièces dès le premier import (il fallait jusqu'ici importer une seconde fois).

Dépannage

Problèmes d'import

  • Vérifiez l'encodage du fichier CSV (UTF-8 recommandé) et qu'il compte au moins 2 colonnes.
  • Si la première ligne contient des noms de colonnes, cochez « 1ʳᵉ ligne = en-têtes ».
  • Si les colonnes sont mal reconnues, ouvrez « Adapter le mapping » sous l'aperçu.
  • Une alerte surlignée en jaune dans l'historique (ex. pages vides d'un PDF) explique ce qui a été ignoré et pourquoi.

Revenir en arrière

  • Cmd+Z annule les dernières modifications du tableau.
  • Une copie de la base est faite automatiquement avant chaque nettoyage de doublons et avant un import (au plus une par 24 h). Les 2 dernières sont gardées, plus 2 copies faites avant des opérations exceptionnelles.
  • Configuration → Restaurer une sauvegarde… remet une copie en place (l'application se ferme ensuite ; relancez-la).

Installer l'application sur un autre poste

1. Créer l'export (sur le poste d'origine)

  1. Configuration → Exporter l'application…
  2. Choisissez le système du poste cible : Windows ou macOS.
  3. Choisissez un dossier de destination (Bureau recommandé).
  4. Patientez 2 à 3 minutes. Une archive 1001pieces_export_windows_AAAAMMJJ_HHMM.zip (ou …_macos_…) est créée, environ 350 Mo.

L'archive contient l'application, la base de données la plus récente, ce guide et les fichiers de test d'import. Les sauvegardes et les journaux restent sur le poste d'origine. Envoyez l'archive par un service de transfert de gros fichiers ou une clé USB.

2. Sur un PC Windows (10 ou 11, 64 bits)

Rien à installer : Python et tout le nécessaire sont dans l'archive.

  1. Si l'archive a été téléchargée : clic droit sur le .zip → Propriétés → cocher Débloquer → OK.
  2. Clic droit sur le .zip → Extraire tout… → choisir un dossier court (ex. C:\1001pieces ou Documents).
  3. Dans le dossier extrait, double-clic sur 1001pieces_autofill.bat.
  4. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même (une seule fois).
  5. Raccourci sur le Bureau : clic droit sur 1001pieces_autofill.bat → Envoyer vers → Bureau (créer un raccourci).
Ne lancez pas l'application depuis l'intérieur du .zip : extrayez-le d'abord. Si l'application ne s'ouvre pas, lancez 1001pieces_autofill_console.bat : une fenêtre noire affiche le message d'erreur.

3. Sur un Mac

Prérequis : un Mac du même type que celui qui a fait l'export (Apple Silicon ou Intel) et la même version de Python, indiquée dans la fenêtre d'export et dans README_INSTALL.md (par exemple 3.13). Si elle manque : brew install python@3.13 ou l'installeur de python.org.

  1. Double-clic sur le .zip pour l'extraire.
  2. Double-cliquez sur install.command : trouve le bon Python, débloque le dossier et installe les dépendances (une seule fois). S'il ne trouve pas le bon Python, il l'indique et dit comment l'installer ; relancez-le ensuite.
  3. Double-cliquez sur 1001pieces_autofill.app : lance l'application.
Si l'application ne s'ouvre pas, lancez 1001pieces_autofill_console.command : une fenêtre Terminal affiche le message d'erreur.
Aucune connexion internet n'est nécessaire sur le poste cible, ni sous Windows ni sous macOS. Chaque poste travaille ensuite sur sa propre copie de la base : les modifications ne se synchronisent pas entre postes.

Assistance

En cas de problème, consultez les logs via Journal dans la barre d'outils (ou F12). Les fichiers sont aussi dans le dossier data/logs de l'application.
